# Демо-бот салона «Студия Лана»

Telegram-бот для салона красоты: цены, запись на свободное время, ответы на частые вопросы, передача заявок и вопросов администратору.

В демо-режиме (без ADMIN_CHAT_ID) бот показывает клиенту, как заявку видит администратор, с кнопками «Подтвердить» и «Отклонить». Так в одном чате видно весь цикл.

## Запуск

1. В @BotFather: `/newbot`, задать имя и username, скопировать токен. Токен никому не отправлять.
2. Залить файлы в новый репозиторий на GitHub (содержимое папки, а не саму папку).
3. Vercel: Add New Project, импортировать репозиторий, в Environment Variables добавить:
   - `TELEGRAM_TOKEN`: токен от BotFather
   - `WEBHOOK_SECRET`: любая длинная строка из латинских букв и цифр
   - `ADMIN_CHAT_ID` (необязательно): чат, куда слать заявки
   Затем Deploy.
4. Открыть в браузере `https://<проект>.vercel.app/api/setup`. В ответе должно быть `"ok": true`.
5. Написать боту `/start`.

## Под нового клиента

Все данные салона лежат в `lib/salon.js`: название, адрес, график, услуги, цены, частые вопросы. Логику трогать не нужно.

## Проверка без Telegram

`node test.js` прогоняет все сценарии и печатает ответы бота.
